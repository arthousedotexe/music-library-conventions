## .cue, .log, and .accurip files

`.cue`, `.log` and `.accurip` files are named `CD<Disc number>`, i.e. `CD1.cue`, `CD1.log`, `CD1.accurip`, `CD2.cue`, `CD2.log`, `CD2.accurip`, etc.  

I generate `.accurip` files through [CUETools](https://cue.tools/wiki/CUETools) program for verification of third-party rips based on existing `.log` files.
