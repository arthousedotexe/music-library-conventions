## .cue, .log и .accurip файлы

`.cue`, `.log` и `.accurip` файлы имеют наименование `CD<Номер диска>`, т.е. `CD1.cue`, `CD1.log`, `CD1.accurip`, `CD2.cue`, `CD2.log`, `CD2.accurip` и так далее.  

Я генерирую `.accurip` файлы через программу [CUETools](https://cue.tools/wiki/CUETools) для повторной верификации сторонних рипов на основе имеющихся `.log` файлов.
