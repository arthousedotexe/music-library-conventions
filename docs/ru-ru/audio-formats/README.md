# Аудиоформаты

Я стараюсь получить максимально возможное качество релизов, поэтому почти вся моя библиотека состоит из lossless файлов.  
Используемый lossless кодек: ```FLAC```, уровень сжатия 8.  
При конвертации из других lossless форматов (```ALAC```, ```WAV```) во ```FLAC``` я сохраняю оригинальную битовую глубину и частоту дискретизации.

Если я не смог получить релиз в lossless формате, то тогда я стараюсь получить самый высококачественный релиз в lossy формате с учётом кодека и битрейта.

## Контрольные суммы

Я использую контрольные суммы ```MD5``` только для ```FLAC```, потому что они в него уже встроены для незакодированных аудиоданных. Они находятся в метаданных внутри блока ```STREAMINFO``` (подробнее [здесь](https://www.rfc-editor.org/rfc/rfc9639.html#name-streaminfo)) и могут использоваться для проверки целостности незакодированного аудио независимо от изменений метаданных.  
Другие lossless форматы я конвертирую в FLAC, поэтому они здесь не рассматриваются.  

Для lossy форматов я не использую контрольные суммы аудиопотока из-за их недетерминированности. Из-за различий в компиляторах, архитектурах, реализаций внутри самих кодеков (например, в ```Opus``` есть реализация с фиксированной точкой и с плавающей запятой - fixed-point и floating-point, подробнее [здесь](https://github.com/xiph/opus/blob/main/README) в разделе Portability notes), декодерах, настройках конвертации и еще много каких переменных, декодированный вывод PCM не обязательно каждый раз будет одинаковым, что лишает проверку целостности смысла.

Я также не использую контрольные суммы для всего файла, потому что изменения в метаданных, обложке, отступах между тегами, или других данных, не связанных со аудиопотоком, изменили бы эту контрольную сумму, даже если бы сам аудиопоток остался идентичным.
