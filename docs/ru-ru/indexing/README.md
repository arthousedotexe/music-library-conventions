# Индексация

Индексный файл (```index.md```) находится рядом с аудиофайлами. Синтаксис файла: Markdown, язык файла: Английский.  
В нём содержится краткая информация о релизе, а именно:

- Название альбома (```Album```);

- Альтернативные названия, ромадзи, переведенные названия альбома - при необходимости;  
  Например: ```エルマ, Eruma```

- Исполнитель альбома (```Album Artist```);

- Другие псевдонимы исполнителя, ромадзи, переведенные псевдонимы - при необходимости;  
  Например: ```Lana Del Ray, Lizzy Grant, Elizabeth Grant, May Jailer, Sparkle Jump Rope Queen```

- Год выхода альбома (год из тега ```Date```);

- Жанры альбома (```Genre```);

- Поджанры альбома (```Style```);  
  Примечание: содержимое тегов жанра и поджанра может дублироваться, например, ```Drumstep```.

- Общая длительность альбома;

- Пометка об экстра материалах (буклеты, обложки, тексты) - при необходимости;

- Качество в формате: `<Источник> [<Кодек>/<Битовая глубина или битрейт и тип битрейта>/<Частота дискретизации>]: <Номера песен - при необходимости>`;  
  - Например, для lossless альбома: `WEB [FLAC/24-bit/96 kHz]`  
  - Для lossy альбома: `WEB [AAC/256 kbps VBR/48 kHz]`  
  - Для компиляции/альбома треков разного качества:

    ```text
    WEB [FLAC/16-bit/44.1 kHz]: tracks 1-7, 10-14
    WEB [MP3/320 kbps CBR/44.1 kHz]: track 8
    WEB [AAC/192 kbps VBR/48 kHz]: track 9
    ```

- Треклист;  
  Примечание №1: если в релизе один диск, то номера треков пишутся без номера диска, но сохраняется лидирующий ноль, например: ```01```, ```09```.  
  Если в релизе несколько дисков, то номер диска учитывается, например: ```1.02```, ```2.13```. Также пишется номер диска перед треками.  
  Примечание №2: если изначально название трека было на другом языке, например, на японском, то в скобочках должно быть написано оригинальное название: ```The flowers are also noisy (花も騒めく)```

- Различного рода пометки - при необходимости;

- Хештеги для поиска, а именно:
  - Источник;
  - Год выхода альбома;  
    Примечание: сначала пишется год, а потом буква y, потому что теги, содержащие только числа, воспринимаются как цвета. Например: ```2012y```
  - Десятилетие, в котором вышел альбом (например, ```2010s```, ```1980s```);
  - Жанры (дефисы и пробелы убираются), подробнее [здесь](https://support.discogs.com/hc/en-us/articles/360005055213-Database-Guidelines-9-Genres-Styles);
  - Поджанры (дефисы и пробелы убираются);  
  - Вокал или инструментал. Если вокал, то женский, мужской или еще какой-то (например, ```instrumental```, ```femalevocalist```, ```malevocalist```, ```choir```);
  - Инди-хештег (т.е. ```indie```);
  - Язык исполнения (например, ```english```, ```russian```, ```german```, ```japanese```);  
  - Другие хештеги.
