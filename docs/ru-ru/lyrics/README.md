# Тексты песен

Тексты песен находятся рядом с аудиофайлами. Имеют такое же название, но другое расширение: ```.lrc```. Далее, такие файлы будут называться lyrics-файлами.

Например: рядом с песней с названием ```1.03. Evening calm,Somewhere,Fireworks.flac``` будет лежать lyrics-файл ```1.03. Evening calm,Somewhere,Fireworks.lrc```.

Содержимое lyrics-файлов можно разделить на две составляющие:

- Теги в начале файла, заключенные в квадратные скобочки;
- Текст песни.

## .lrc теги

Подробнее о тегах можно прочитать [здесь](https://en.wikipedia.org/wiki/LRC_(file_format)).

Я использую следующие теги: ```ti```, ```ar```, ```al```, ```length```.  
Например:

```lrc
[ti: Nobody's Fool]
[ar: Avril Lavigne]
[al: Let Go]
[length: 03:57]
```

## Тексты

Запрещенные символы в тексте:

- Альтернативные кавычки и апострофы: ```„```, ```“```, ```’```, ```‘``` и другая типографика;
- Управляющие ASCII-символы и неразрывный пробел;
- Другие замечательные символы, которые не прочитает ни один аудиоплеер в мире.

Всё остальное разрешено.

Я использую синхронизированные тексты песен, которые выглядят так:

```lrc
[00:11.50] (Step up, step up) step up
[00:14.79] (Step up, step up) step up
[00:17.13] (Step up, step up)
[00:20.08] (Step up)
[00:21.98] Fall back
[00:22.76] Take a look at me and you'll see
```
