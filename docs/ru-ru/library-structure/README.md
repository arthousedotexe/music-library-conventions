# Структура библиотеки

## Структура директорий

Корневой директорией библиотеки является `Music`

Путь до каждого альбома имеет следующую структуру:

```text
<Исполнитель альбома>/<Год выхода альбома> - <Название альбома>
```

Например:

- `Music/Ice Cube/1992 - The Predator`
- `Music/Lana Del Rey/2012 - Born to Die – The Paradise Edition (Special Version)`

## Наименование файлов

Каждый трек внутри директории альбома имеет следующее наименование:

```text
<Номер диска>.<Номер трека с лидирующим нулём>. <Название трека>.<Расширение>
```

Например:

- `1.07. It Was a Good Day.flac`
- `2.01. Ride.flac`

Соответствующие файлы с текстами используют то же базовое имя файла, но другое расширение - `.lrc`:

- `1.07. It Was a Good Day.lrc`
- `2.01. Ride.lrc`

Запрещенные символы в названиях:

- Недопустимые символы в Windows: `/\:*?"<>|`;
- Управляющие ASCII-символы;
- Зарезервированные имена устройств в Windows;
- Неразрывные пробелы.

Для треков я использую английские и русские названия. Если трек имеет название на другом языке, например, на японском, то тогда я использую романизированную форму или английский перевод, первое предпочительнее, где это уместнее.  
Например: трек с названием `心に穴が空いた` будет иметь название `Kokoro ni Ana ga Aita` или `Hole In The Heart`.  
Это необходимо для удобного поиска.

## Структура альбома

Каждая директория альбома имеет следующую структуру:

- Аудиофайлы (`.flac`, `.m4a`, `.mp3` и так далее), подробнее [здесь](/ru-ru/audio-formats/ 'Аудиоформаты')
- Тексты песен (`.lrc`), подробнее [здесь](/ru-ru/lyrics/ 'Тексты песен')
- Внешняя обложка альбома (`cover`), подробнее [здесь](/ru-ru/covers-and-booklets/?id=Внешняя-обложка-альбома 'Обложки, буклеты')
- Индексный файл (`index.md`), подробнее [здесь](/ru-ru/indexing/ 'Индексация')
- Директория с буклетами (`booklet`) - при необходимости, подробнее [здесь](/ru-ru/covers-and-booklets/?id=Буклеты 'Обложки, буклеты')
- Директория с другими обложками (`covers`) - при необходимости, подробнее [здесь](/ru-ru/covers-and-booklets/?id=Дополнительные-обложки 'Обложки, буклеты')
